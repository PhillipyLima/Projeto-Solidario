# Ponte Solidária

## Sobre o Projeto
O **Ponte Solidária** é uma plataforma web criada para ajudar na organização e gestão de doações. O objetivo é facilitar a conectividade entre pessoas que querem ajudar e instituições ou comunidades que precisam de apoio.

Esse projeto usa a tecnologia para transformar a forma como as doações são feitas, tornando tudo mais acessível, organizado e eficiente.

## Funcionalidades
- Organização das doações.
- Gerenciamento de doadores e instituições.
- Acompanhamento fácil das doações.
- Interface administrativa com várias telas para facilitar a navegação.

## Tecnologias Usadas
- HTML5
- CSS3
- JavaScript

## Objetivo do Projeto
O projeto tem como foco aprender e aplicar conceitos básicos de desenvolvimento front-end, organização de interfaces e experiência do usuário (UX/UI), juntando tecnologia e solidariedade.

## Como Usar
Basta abrir os arquivos HTML no navegador para usar a plataforma e explorar suas funcionalidades.
